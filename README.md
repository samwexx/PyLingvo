# PyLingvo

PyLingvo ir 2D izglītojoša spēle, kas izstrādāta, izmantojot Unity.  
Projekts tika izveidots kā mācību projekts.


## Par projektu

PyLingvo ir spēles prototips, kas koncentrējas uz spēles pamata mehānikām, spēlētāja mijiedarbību un NPC (nevadāmo personāžu) uzvedību.  
Galvenais projekta mērķis ir izpētīt spēļu izstrādes pamatus.


## Izmantotās tehnoloģijas

- Unity
- C#


## Funkcionalitāte

- Spēlētāja kustība
- Mijiedarbība ar NPC
- Uz uzdevumiem balstīta spēle

## Spēles lejupielāde

1. Atveriet projekta GitHub lapu.
2. Dodieties uz sadaļu **Releases** (labajā pusē).
3. Lejupielādējiet arhīvu (`PyLingvo_Build_W.zip`).
4. Atarhivējiet failu savā datorā.
5. Atveriet mapi un palaidiet `.exe` failu.
